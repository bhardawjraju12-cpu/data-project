# 📊 Data Warehouse and Analytics Project

## 📌 Project Overview

This project demonstrates an end-to-end data warehousing and analytics workflow, covering data integration, data cleaning, dimensional modeling, and business intelligence. It transforms raw sales data into a structured format that supports meaningful analysis and data-driven decision-making.

The project is designed to showcase practical skills in SQL-based data engineering and analytics.

---

## 🎯 Project Objectives

- Build a centralized data warehouse using SQL Server.
- Integrate sales data from ERP and CRM source systems.
- Improve data consistency through data cleaning and validation.
- Develop a structured data model for efficient analytical queries.
- Generate actionable business insights through SQL analysis and reporting.

---

## 🏗️ Project Structure

### 1. Data Warehousing — Data Engineering

**Goal:** Create a centralized repository for sales-related information from multiple source systems.

**Key Activities:**
- **Data Ingestion:** Import ERP and CRM datasets provided in CSV format.
- **Data Cleaning:** Identify and resolve missing values, inconsistencies, and data quality issues.
- **Data Integration:** Combine data from different systems into a unified data model.
- **Data Modeling:** Organize data to support efficient querying and analytical reporting.
- **Documentation:** Document the data model and transformation logic for easier understanding and maintenance.

**Scope:** The warehouse focuses on the latest available dataset without maintaining historical records.

### 2. Business Intelligence — Data Analytics

**Goal:** Use SQL to analyze sales data and uncover insights into customer purchasing behavior.

**Key Activities:**
- Analyze customer purchasing patterns.
- Explore sales performance and related business metrics.
- Write SQL queries to summarize and compare business data.
- Identify useful trends and patterns to support business decisions.
- Present analytical findings in a clear and understandable format.

---

## 🛠️ Tools and Technologies

- **Database:** Microsoft SQL Server
- **Query Language:** SQL
- **Data Sources:** ERP and CRM CSV files
- **Data Engineering:** Data cleaning, integration, and modeling
- **Analytics:** SQL-based business analysis and reporting
- **Version Control:** Git and GitHub

## 📂 Data Sources

The project uses two primary data sources:

- **ERP (Enterprise Resource Planning):** Provides business transaction and sales-related data.
- **CRM (Customer Relationship Management):** Provides customer-related information.

The datasets are integrated to create a consistent foundation for sales analysis.
